## Resumen para la sección «Uso de inteligencia artificial» del informe

- **Herramienta:** Claude Code (Claude Opus 5.5, Anthropic), en la aplicación de escritorio de Claude.
- **Alcance del apoyo:** instalación del entorno, código fuente completo (Python, JavaScript, HTML y CSS), pruebas automáticas, documentación técnica (punto 9), guion de la demo y registros de riesgos. **No** se usó para el diseño del Hito 1 (fórmulas, reglas RN01–RN12 y juegos de prueba), que fue la especificación que el código debía cumplir.
- **Control del grupo:** cada fase se revisó y aprobó antes de continuar («continúa»); el grupo aprobó los ajustes A–E del 20/11/2026 y la decisión sobre la mora; los resultados se verificaron contra los juegos A y B del informe (159 pruebas automáticas y una prueba manual completa).
- **Porcentaje sugerido para el código del Hito 2:** alrededor de 85–90 %, según la columna «Apoyo IA estimado» de cada fase. El porcentaje final lo declara el alumno puente con el criterio que el grupo sustente.
- **Pendiente del grupo:** indicar el alumno puente, ajustar los porcentajes y completar también la tabla de aportes del Hito 1 (ChatGPT).
